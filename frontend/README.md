# Frontend

This directory is reserved for the planned React self-service portal.

## Planned Responsibilities

- OIDC login flow through Keycloak
- image catalog display
- desktop launch request form
- lifecycle status display
- connect action
- delete action
- admin views where authorized

The frontend improves usability but is not a security boundary. All authorization is enforced by the backend.

No frontend implementation is present in Phase 1.
